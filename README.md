# SIR - Sistema Inteligente do Ramo

Projeto para automatizar processos, centralizar e facilitar a manutenção de dados do ramo estudantil.

## MAVI - Monitoramento de Ativos e Verificação Inteligente
*em construção*  
Base de dados para uma data plataform.  
Centraliza metadados, texto e link para os arquivos em diferentes fontes.  
Dados são armazenados num banco de dados local, com ferramentas de busca.
